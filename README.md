# 💸 FlowPay Backend

A secure and intelligent expense-sharing backend built with **Spring Boot**.

FlowPay helps users manage shared expenses, split bills, monitor budgets, receive AI-powered spending insights, and track recurring expenses.

---

## 🚀 Features

- ✅ JWT Authentication & Authorization
- ✅ User Registration & Login
- ✅ Expense Groups
- ✅ Group Member Management
- ✅ Expense Tracking
- ✅ Expense Categories
- ✅ Smart Settlement Algorithm
- ✅ Budget Management
- ✅ Monthly Reports
- ✅ User Reports
- ✅ Receipt Upload
- ✅ Recurring Expenses
- ✅ Daily Reminder Scheduler
- ✅ Notifications
- ✅ AI Spending Insights
- ✅ AI Recommendations
- ✅ Admin Dashboard
- ✅ Swagger API Documentation
- ✅ Global Exception Handling
- ✅ Production Configuration
