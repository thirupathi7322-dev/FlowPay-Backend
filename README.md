# FlowPay Backend

A Splitwise-inspired expense sharing backend built with Spring Boot.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- JWT Authentication
- Maven

## Features

### Phase 1
- User Registration
- User Management

### Phase 2
- BCrypt Password Authentication
- Login API

### Phase 3
- JWT Authentication
- Protected APIs
- Stateless Security

## Project Structure

src
├── config
├── controller
├── dto
├── entity
├── repository
├── service
└── exception

## APIs

POST /api/users/register

POST /api/auth/login

GET /api/users (JWT Protected)
